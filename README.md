# QKD Lab

Atelier d'apprentissage sur la distribution quantique de clés (QKD) : carte du sujet, explications courtes, animations, quiz, schémas et notes.

- Un seul fichier : `index.html`. Aucune dépendance, aucune requête externe.
- Les notes et schémas sont enregistrés dans le navigateur du visiteur. Utiliser « Exporter » pour les sauvegarder.
- Le contenu est pédagogique et s'appuie sur des sources publiques (liens dans chaque section). À vérifier avant toute citation.
